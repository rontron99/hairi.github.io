# Hairizuwan Portfolio

Modern responsive single-page portfolio, redesigned from the supplied CV and previous website HTML.

## Run locally
Open `index.html` in a browser, or start VS Code Live Server.

## Publish on GitHub Pages
1. Upload `index.html`, `styles.css`, `script.js` and `Hairizuwan_CV.pdf` to the root of your GitHub Pages repository.
2. In GitHub go to **Settings → Pages**, choose **Deploy from a branch**, and select your published branch/root directory.
3. Update the portfolio's GitHub profile link in `index.html` if you use a different account.

## Notes
- Project illustrations are conceptual, not screenshots of proprietary software.
- Private identity numbers, physical home address and referees were intentionally excluded from the public webpage.
- The original CV PDF is included unchanged and may contain personal details. Consider preparing a public-facing redacted CV before deploying publicly.
- The initial CV did not list TypeScript; the portfolio should not claim it. Update technologies based on your verified experience.
